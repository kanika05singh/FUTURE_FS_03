# Urban Bite — Restaurant Website

A complete, production-ready marketing website for **Urban Bite**, a modern wood-fired grill & bar in Koramangala, Bengaluru.

Built for **Future Interns — Full Stack Web Development, Task 3 (2026)**.

## Features

- Fully responsive (320px → 1440px+)
- Sticky navbar with scroll-based styling
- Animated mobile navigation menu
- Hero section with animated entrance, trust stats, and floating review card
- About section with animated count-up statistics
- Menu/Services grid with live category filtering
- Why Choose Us feature grid
- Gallery with keyboard-accessible lightbox
  - Escape key to close
  - Arrow keys to navigate
  - Click outside to close
- Testimonials carousel using scroll-snap
- Location section with Google Maps integration
- Get Directions, Call, and WhatsApp actions
- Contact form with client-side validation
- Loading and success states
- Floating WhatsApp button
- Semantic HTML and accessible form labels
- Visible focus states
- `prefers-reduced-motion` support
- SEO metadata including title, description, Open Graph tags, and favicon

## Tech Stack

- React 18
- Vite
- Tailwind CSS 3
- lucide-react
